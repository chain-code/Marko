# 中文排版

## 长段落

在一个安静的下午，打开编辑器，把脑子里零散的想法一条条写下来。好的写作工具应该让人感觉不到它的存在：文字出现在哪里，排版就跟到哪里；需要格式的时候，按一下快捷键就有，不需要的时候，它也不会打扰。Markdown 正是这样一种格式——它足够简单，简单到用纯文本就能表达标题、列表、引用和代码；它也足够灵活，灵活到可以写技术文档、读书笔记、会议纪要，甚至一本书。

## 中英文混排

Marko 使用 Vue 3 和 TypeScript 编写，编辑器内核计划换成 ProseMirror，结构解析用 Lezer。中文与 English 之间、中文与数字 2026 之间的间距，以及全角标点“引号”、（括号）、《书名号》和半角标点 "quotes" (parens) 的样子，都在这一段里。

## 标点挤压

“这是一句被引号包起来的话。”他说，“第二句也是。”——破折号后面接着写……省略号之后结束。

## 列表里的中文

1. 第一步：准备好要写的内容，列一个提纲，提纲可以很粗略，之后再慢慢补充细节。
2. 第二步：按提纲写正文。
3. 第三步：通读一遍，删掉多余的话。
