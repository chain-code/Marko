# 行内格式

**粗体**、__下划线写法的粗体__、*斜体*、_下划线写法的斜体_、***粗斜体***、~~删除线~~、<u>下划线</u>、`行内代码`。

嵌套：**粗体里的*斜体*和`代码`**，*斜体里的[链接](https://example.com)*。

中文和强调：这是**中文粗体**，这是*中文斜体*，强调紧挨着中文标点**“引号”**。

链接：[行内链接](https://example.com "标题")、[引用链接][ref]、[简写引用][]、<https://example.com/autolink>、裸网址 https://example.com/bare、邮箱 <hello@example.com>。

[ref]: https://example.com/reference "引用链接的标题"
[简写引用]: https://example.com/collapsed

扩展（需要在设置里打开）：==高亮==、上标 x^2^、下标 H~2~O。

Emoji：:smile: :rocket: :+1:

HTML：<kbd>Ctrl</kbd>+<kbd>S</kbd>、<span style="color: #d14">红色文字</span>、<mark>mark 标签</mark>、换行<br>之后。

实体和转义：&amp; &lt; &gt; &copy; &#x4E2D; \*不是斜体\* \`不是代码\`。

行内公式：$E = mc^2$，以及 $\sum_{i=1}^{n} i = \frac{n(n+1)}{2}$。

脚注引用[^1]，第二个脚注[^note]。

[^1]: 第一个脚注的内容。
[^note]: 第二个脚注，带**格式**。
