# 表格

| 左对齐 | 居中 | 右对齐 |
| :--- | :---: | ---: |
| 苹果 | 10 | 3.50 |
| 香蕉 | 200 | 12.00 |
| 很长很长的单元格内容，用来观察换行 | 3 | 0.99 |

带格式的单元格：

| 功能 | 写法 | 说明 |
| --- | --- | --- |
| 粗体 | `**粗体**` | **效果** |
| 链接 | `[x](url)` | [示例](https://example.com) |
| 换行 | `a<br>b` | 第一行<br>第二行 |
| 竖线 | `a \| b` | a \| b |
| 公式 | `$x^2$` | $x^2$ |
